MulleCG + MulleGLFW

glfw-draw-simple

Just draws three bars of color. Can't get much simpler than that. If this demo fails, something very basic is going wrong. The window is a basic GLFW window. We need to subclass GLFWWindow actually to tie MulleCG and MulleGLFW together.

main-glfw-draw-simple.m

MulleCG + MulleUICore

From here on we use MulleUICore to demonstrate MulleCG features.

draw-simple

This is glfw-draw-simple for MulleUICore. It's much, much less code. There is no need for a UIWindow subclass. We don't need to implement -[CGContext setActive:]. We don't have to bother with matching GLFW windows hints with the required GLFW window hints.

main-draw-simple.m

draw

This demo is actually very resource intensive. MulleCG (and nanovg) don't like drawing many discrete lines. Notice the performance problems when resizing (or not)

main-draw.m
