MulleCG + MulleGLFW

In the most basic setup MulleGLFW is used to get access to a window and OpenGL/Vulkan/Metal context. This is more cumbersome than using UIWindow though.

glfw-draw-simple

Just draws three bars of color. Can't get much simpler than that. If this demo fails, something very basic is going wrong. The window is a basic GLFW window. We need to subclass GLFWOSWindow actually to tie MulleCG and MulleGLFW together.

main-glfw-draw-simple.m

glfw-cglayer

This creates a tiny 64x64 offscreen buffer and fills it with a uniform color. Then draws a circle into it. The buffer is written to a BMP file.

main-glfw-cglayer.m

The idea of drawing into CGLayers is expanded on in cglayer.

MulleCG + MulleUICore

From here on UIWindow is used to demonstrate MulleCG features.

draw-simple

This is glfw-draw-simple for MulleUICore. It's much, much less code. There is no need for a window subclass. We don't need to implement -[CGContext setActive:]. We don't have to bother with GLFW windows hints.

main-draw-simple.m

draw

This demo is actually very resource intensive. MulleCG (and nanovg) don't like drawing many discrete lines. Notice the performance problems when resizing. You can pass command line parameter '-r' to use retained (multi-threaded) code. Notice how the problems vanish. If you use '-m' for running retained on the main thread, the problems reappear. Using the retained mode on the main thread can be useful though to detect basic OpenGL/glfw problems.

main-draw.m

cgimage

A very basic textured square. Pretty much the simplest texture example possible.

main-cgimage.m

cgimage-flip

Flipping the textured square along the horizontal axis, the vertical axis and both. This is done with the options in -drawRect:options:context: and can be done on any bitmap image, without having to change it.

main-cgimage-flip.m

cgimage-repeat

Repeat of the textured square along the horizontal axis, the vertical axis and both. This is done with an UIBitmapImage and options in -drawRect:options:context:.

This will create four separate CGImages, since repeat is a property of an individual CGImage:

main-cgimage-repeat.m

cgimage-rotate

Rotate the texture within the rectangle being displayed. You can also achieve rotation, by rotating the rectangle itself, but this rotates the texture:

main-cgimage-rotate.m

cgimage-contentmode

An image that isn't set as CGScaleToFit (which is the default) can be placed into the center (default) or any corner with the .flags.contentMode of the CGDrawableOptions. Not super useful in most cases, as the clamping of OpenGL produces streaks of the outside pixels. This can be done with any bitmap image:

main-cgimage-contentmode.m

cglayer

A drawing (the red/white/blue) flag is rendered into an offscreen framebuffer/texture and then used as an image to draw.

main-cglayer.m

main-particlelayers.m
